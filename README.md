# StyleBound

StyleBound is a World of Warcraft addon for moving transmog outfits between the game client and [stylebound.gg](https://stylebound.gg).

## Features

- Export your current transmog as a compact StyleBound string for the site.
- Import a StyleBound string in-game to preview an outfit, check what you own, and save it to your library.
- Copy a nearby targeted player's visible transmog with `/sb copy`.
- Save, search, organize, preview, share, rename, delete, and promote outfits into Blizzard custom sets.
- Take clean manual screenshots or a quick three-angle auto-shoot set for submissions.
- Toggle the minimap launcher and S.E.L.F.I.E. Camera tracking from the Settings tab.

## Commands

- `/sb` opens the StyleBound panel.
- `/sb screenshot` starts a clean manual screenshot session. Press Escape when you are done.
- `/sb autoshoot` captures a quick three-angle screenshot set.
- `/sb copy` copies your target's transmog into an import preview. For regular use, make a macro with `/sb copy` as the body, drag it to your bars, target a player, then press it.

## Screenshots and Site Uploads

WoW saves screenshots in `World of Warcraft\_retail_\Screenshots`. Sort that folder by date to find your newest StyleBound shots.

On stylebound.gg, import the outfit string from the Export tab and attach the matching screenshots from that folder.

## Privacy

StyleBound stores saved outfits and settings in local WoW SavedVariables. It does not upload data or screenshots automatically.
